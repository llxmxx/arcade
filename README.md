# arcade

<img width="1917" height="906" alt="image" src="https://github.com/user-attachments/assets/0fff6db4-3976-4713-9da9-afba11af5fb1" />

a tiny keyboard-only arcade built with html, css, javascript. no mouse, no tab.

### games
- tic-tac-toe
- snake
- maze

### controls
| key | action |
|-----|-------|
| `← ↑ ↓ →` | navigate |
|`WASD`| in game navigation |
|`Enter`| confirm |
